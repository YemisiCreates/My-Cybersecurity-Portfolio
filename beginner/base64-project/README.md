## What I Did
I used the b64tool cybersecurity CLI project to:
- Encode text
- Decode Base64 strings
- Detect encoding formats
- Peel encoding layers
- Chain encodings

## Commands I Tested

Encode:
uvx b64tool encode "Hello World"

Decode:
uvx b64tool decode "SGVsbG8gV29ybGQ="

Detect:
uvx b64tool detect "SGVsbG8gV29ybGQ="

Peel:
uvx b64tool peel "SGVsbG8gV29ybGQ="

Chain:
uvx b64tool chain "SGVsbG8gV29ybGQ="
