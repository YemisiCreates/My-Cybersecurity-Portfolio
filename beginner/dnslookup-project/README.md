# DNS Lookup Project

## Project Overview

This project focused on DNS investigation, hostname resolution, and domain intelligence gathering using a professional DNS lookup CLI tool.

I performed multiple DNS-related investigations including:
- standard DNS queries
- reverse DNS lookups
- WHOIS analysis
- MX/mail server investigations

The project helped strengthen my understanding of how DNS supports internet communication and how DNS analysis is used in cybersecurity operations.

- MX records (mail servers)
- NS records (authoritative nameservers)
- TXT records (verification/SPF/security metadata)
- SOA records (DNS authority information)
