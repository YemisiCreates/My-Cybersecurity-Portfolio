# Canary Token Generator Project

## Project Overview

This project focused on deception security and honeytoken-based detection techniques using a full-stack Dockerized environment.

I deployed and interacted with a locally hosted canary token platform that generated tripwire artifacts capable of detecting unauthorized interaction attempts.

The project used:
- Go backend services
- React frontend
- PostgreSQL database
- Redis caching/rate-limiting
- Docker Compose orchestration
- Honeytoken/deception security concepts
