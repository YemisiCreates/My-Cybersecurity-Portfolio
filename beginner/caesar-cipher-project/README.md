# Caesar Cipher Security Project

## Project Overview

This project focused on learning classical cryptography concepts using Caesar cipher encryption and decryption techniques.

I practiced encrypting plaintext, decrypting ciphertext, and performing brute-force cracking with frequency analysis to understand how weak encryption methods can be broken by attackers.

The project also helped improve my command-line workflow, GitHub portfolio development, and cybersecurity documentation skills.
